I have been thinking about potential double counting if we include both teams for one match. As a win for team A forces a lose for team B, they are not independent observations. I should have addressed this issue earlier, but it’s not too late. There are two ways to fix it. Option 1: For each match, randomly assign one team (A or B) as the observation. Option 2: see below

Stacked Data with Cluster-Robust Standard Errors
If you want to keep the data from both teams' perspectives without splitting them arbitrarily, you can stack the data (two rows per match) but use a stacked logistic regression with clustered standard errors by match_id.
How it works: You include two rows per match (Row A: Team 1 vs Team 2; Row B: Team 2 vs Team 1).
How it solves double-counting: By clustering the standard errors at the match_id level, the regression mathematically adjusts the sample size back down to the true number of matches. It corrects the artificial deflation of your p-values.
Regression Requirement: You must not include an intercept, and you must use a cluster-robust covariance matrix (e.g., cov_type='cluster' in Python).
